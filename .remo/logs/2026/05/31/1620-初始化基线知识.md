# 2026-05-31 16:20 初始化基线知识

## 类型

决策

## 摘要

ReMo 增加了初始化完整基线知识文档集合的能力，用于支持后期引入到已有项目的场景。

## 背景

ReMo 的目标是节省上下文并避免频繁扫描整个代码库。如果它被引入到一个已经存在的项目，而只创建 `.remo/knowledge/index.md` 或少量文件，后续 Agent 仍然可能不知道不同类型的项目知识应该沉淀到哪里。

## 关键信息

- ReMo 初始化时应创建 `.remo/logs/` 和 `.remo/knowledge/`。
- ReMo 初始化时应创建 `index.md`、`project-overview.md`、`architecture.md`、`domain-model.md`、`workflows.md`、`decisions.md`、`conventions.md`、`faq.md` 和 `glossary.md`。
- 对已有项目，可以从 README、docs 和顶层目录结构中提取安全事实。
- 不确定的内容用 `Status: To be filled` 标注，并列出具体待确认问题。
- 初始化完成后，应在 `.remo/logs/` 中记录安装日志。

## 决策或结果

ReMo 从“按需创建知识文件”调整为“安装时创建完整基线知识文档集合”，为后续上下文路由和知识回写提供稳定入口。

## 后续行动

- [ ] 后续给其他项目安装 ReMo 时，使用完整基线知识文档集合。
- [ ] 评估是否需要提供自动初始化脚本。
