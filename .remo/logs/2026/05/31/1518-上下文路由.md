# 2026-05-31 15:18 上下文路由

## 类型

决策

## 摘要

ReMo 从偏记录的工作流升级为上下文路由工作流。它的目标被明确为：在扫描代码库之前先读取整理过的项目知识，从而减少上下文使用。

## 背景

原始 ReMo 设计可以保存日志和知识，但还不能保证未来 Agent 在大范围探索前先使用知识库。这限制了它节省 token 的能力。

## 关键信息

- 新增 `.remo/knowledge/index.md` 作为必需的知识入口。
- 新增任务开始规则：大范围探索代码库前先读取知识索引。
- 新增从任务类型路由到最小相关知识文件集合的规则。
- 新增知识文件变化时维护索引的要求。
- 更新日志文件命名规则，加入年月日目录和小时分钟文件名：`.remo/logs/YYYY/MM/DD/HHMM-title-in-memory-language.md`。

## 决策或结果

ReMo 被定义为上下文效率系统，包含两个循环：任务开始时读取路由后的知识，任务结束时将稳定发现回写。

- [ ] 只有在出现稳定内容时才新增更多知识文件。
