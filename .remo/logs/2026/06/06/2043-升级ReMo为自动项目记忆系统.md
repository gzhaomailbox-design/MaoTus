# 升级 ReMo 为自动项目记忆系统

## Type

auto_absorb

## Summary

ReMo 的产品定位从手动 Agent 记忆协议升级为面向 Coding Agent 的自动项目记忆系统。系统目标改为在任务边界和 Git checkpoint 自动组织并写入正式 Markdown knowledge，让未来 Coding Agent 更少加载上下文、减少重复探索和返工。
