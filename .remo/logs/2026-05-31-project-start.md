# 2026-05-31 项目启动

## 类型

里程碑

## 摘要

MaoTus 被初始化为一个用于管理 Vibe Coding 实践中沉淀出来的 skills 的仓库。第一个 skill 项目是 ReMo，也就是 Repo Memory。

## 背景

这个项目需要一套结构来保存可复用的 skills，并在仓库自身实践这些 skills。ReMo 是第一个案例，因为它直接支持项目知识的持续沉淀。

## 关键信息

- GitHub 远程仓库是 `https://github.com/gzhaomailbox-design/MaoTus.git`。
- 仓库以 ReMo 作为第一个 skill 项目。
- ReMo 将过程日志和抽象后的项目知识分开管理。
- 这个仓库本身也是第一个由 ReMo 管理的实践项目。

## 决策或结果

确定了 MaoTus 的初始方向，并选择 ReMo 作为第一个要实现和实践的 skill。
